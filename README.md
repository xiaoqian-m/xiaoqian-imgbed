# xiaoqian-imgbed

A simple public image bed repo.

## How we use it
- Put images under `images/`.
- Commit + push.
- Share the raw URL.

## URL patterns
After you push, a file like `images/demo.png` can be accessed via:

- Raw (recommended for direct image viewing):
  `https://raw.githubusercontent.com/xiaoqian-m/xiaoqian-imgbed/main/images/demo.png`

- GitHub web page:
  `https://github.com/xiaoqian-m/xiaoqian-imgbed/blob/main/images/demo.png`

## Notes
- This repo is public. Do NOT upload sensitive content.
